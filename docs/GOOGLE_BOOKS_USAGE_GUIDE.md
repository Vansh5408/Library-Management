# Using Google Books Search - Visual Guide

## 🎯 Access the Feature

### For Regular Users
1. Log in to your account
2. Go to **User Dashboard**
3. Look for tabs at the top:
   - My Books
   - Borrow History
   - My Reservations
   - **→ Search External Books** ← Click here!

### For Admins/Librarians
1. Log in as admin
2. Go to **Admin Dashboard**
3. Look for tabs at the top:
   - Books
   - Users
   - Statistics
   - **→ Search External Books** ← Click here!

### Step 1: Click "Add to Library"

- Book cards in search results
- Book details modal

│                                      │

The book is immediately available in:
- **Admin Dashboard** → Books tab
- **User Dashboard** → Browse books
- Can be borrowed by users
- Appears in search results

## 🎯 Search Tips

### 1. General Search
```
Search Query: "programming python"
→ Finds books about Python programming
```

### 2. Author Search
```
Author: "Tolkien"
→ Finds all books by J.R.R. Tolkien
```

### 3. Subject Search
```
Subject: "fantasy"
→ Finds all fantasy books
```

### 4. ISBN Search (Most Precise)
```
ISBN: "9780140283334"
→ Finds exact book by ISBN
```

### 5. Combined Search
```
Search Query: "lord rings"
Author: "Tolkien"
Subject: "fantasy"
→ Very specific results
```

## 🎨 Filter by Source

Choose where to search:

```
● All Sources
  → Searches Google Books AND Open Library
  → More results, best for general searches

○ Google Books Only
  → Searches only Google Books
  → Best for newer, commercial books
  → Better cover images

○ Open Library Only
  → Searches only Open Library
  → Best for older, public domain books
  → Free digital copies available
```

## 🔄 Workflow Example

### Scenario: Adding "Clean Code" to Your Library

1. **Open Search Tab**
   - User Dashboard → Search External Books

2. **Search**
   - Search Query: "clean code"
   - Author: "Robert Martin"
   - Click "Search Books"

3. **Review Results**
   - See "Clean Code: A Handbook of Agile Software Craftsmanship"
   - Click "View Details"

4. **Verify Book Info**
   - Check author, description, pages
   - Note the ISBN for reference

5. **Add to Library**
   - Click "Add to Library"
   - See success confirmation
   - Optionally set number of copies

6. **Book is Now Available**
   - Users can search for it
   - Users can borrow it
   - Admins can manage it

## 💡 Pro Tips

### For Finding Specific Books
- **Use ISBN** when you know it (most accurate)
- **Combine filters** for precise results
- **Check both sources** if not found in one

### For Browsing
- **Click popular subjects** for quick categories
- **Use broad queries** like "sci-fi" or "business"
- **Browse through pages** to discover titles

### For Library Management
- **Check before adding** if book already exists
- **Add multiple copies** if needed after import
- **Update descriptions** after importing if needed
- **Verify author names** (may have variations)

## 🐛 Common Issues & Solutions

### "No results found"
- Try broader search terms
- Check spelling
- Try different source (All/Google/OpenLibrary)
- Try searching by author only

### "Failed to search"
- Check internet connection
- Verify backend server is running
- Check browser console for errors
- Try refreshing the page

### "Book already exists in library"
- Click "View Details" to see existing book
- Update quantity in admin panel instead
- No duplicates are allowed
